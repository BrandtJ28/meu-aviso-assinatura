# 🚫 Stop Pay - Alerta de Assinaturas

Um Web App (PWA) simples e eficiente para gerenciar suas assinaturas e nunca mais ser cobrado por um serviço que esqueceu de cancelar. 

## ✨ Funcionalidades
* **Cadastro de Assinaturas:** Salve o nome do serviço e a data de vencimento.
* **Armazenamento Local:** Seus dados ficam salvos no seu navegador (privacidade total).
* **Notificações Push:** O app te avisa no dia do vencimento para você realizar o cancelamento.
* **PWA (Progressive Web App):** Pode ser instalado no Android ou iPhone como se fosse um aplicativo nativo.

## 🚀 Como Instalar no Celular

Como este é um PWA, você não precisa baixar na Play Store ou App Store:

### No Android (Chrome):
1. Acesse o link do projeto.
2. Clique nos **três pontinhos** no canto superior direito.
3. Selecione **"Instalar aplicativo"** ou **"Adicionar à tela de inicial"**.

### No iPhone (Safari):
1. Acesse o link do projeto pelo **Safari**.
2. Clique no ícone de **Compartilhar** (quadrado com uma seta para cima).
3. Role para baixo e clique em **"Adicionar à Tela de Início"**.

## 🛠️ Tecnologias Utilizadas
* **HTML5 & CSS3:** Interface responsiva.
* **JavaScript:** Lógica de agendamento e armazenamento.
* **Service Workers:** Para permitir o funcionamento offline e notificações.
* **Web Manifest:** Para transformar o site em um aplicativo instalável.

## 📝 Notas importantes
* As notificações dependem da permissão do navegador. Certifique-se de clicar em **"Permitir"** quando o app solicitar.
* No iOS, as notificações para PWAs funcionam a partir da versão 16.4 do sistema.
